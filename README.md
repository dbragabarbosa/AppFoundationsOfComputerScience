The FoundationsOfComputerScience App is an educational application designed to help computer science students understand concepts of data structures and algorithms. With a didactic approach, the app offers explanations and static and interactive examples on topics such as stacks, queues, arrays, search algorithms (linear and binary), complexity analysis (Big O), and sorting algorithms (SelectionSort, InsertionSort, and BubbleSort).
